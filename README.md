# WaveLab 3D｜从波到 k 空间

一个面向固体物理、量子力学和量子化学初学者的交互式可视化学习网页。

通过实时动画理解：正弦波、复指数、傅里叶分解、波函数、实空间与 k 空间之间的联系。

## 在线使用

直接打开：

**https://denishlab.github.io/wavelab-3d/**

推荐使用电脑端最新版 Chrome 或 Edge 浏览器。网页不需要注册账号，也不需要安装软件。

## 操作方法

1. 使用页面底部的参数滑块，改变振幅、波长、相位等参数。
2. 点击右上方的“2D 对照”或“3D 相位”，切换二维波形与三维复数相位视图。
3. 在3D视图中按住鼠标拖动，可以旋转观察角度；使用滚轮缩放。
4. 点击“重置视角”，恢复默认3D观察位置。
5. 点击“播放”观察随时间变化的波；点击“重置”恢复当前场景参数。
6. 使用“上一步”和“下一步”，按照课程顺序继续学习。
7. 遇到不理解的概念时，点击右侧“为什么？”，查看直觉解释、数学说明和常见误区。

## 本地离线使用

1. 点击仓库右上方 `Code` → `Download ZIP`。
2. 解压下载的 ZIP 文件。
3. 保持下列文件位于同一个文件夹中：
   - `index.html`
   - `styles.css`
   - `app.js`
   - `three-view.js`
4. 双击 `index.html`，使用 Chrome 或 Edge 打开。

不要只下载或转发 `index.html`，否则样式和3D动画无法加载。

## 主要功能

- 波长、振幅、相位和波数的实时调节
- 2D波形与3D复数相位对照
- 复指数与欧拉公式的几何解释
- 傅里叶叠加与频率成分展示
- 实空间与 k 空间的同步观察
- 可展开的“为什么？”深入讲解
